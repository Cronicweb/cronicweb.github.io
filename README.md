# Pinnacle Mall — MallOS

Website &amp; interactive app prototype for **Pinnacle Mall**, a 6-floor mall, hosted for free on **GitHub Pages**.

**MallOS** is a unified operations suite covering hotel booking, food ordering &amp; delivery, captain ordering with kitchen displays, real-time inventory, automated GST billing, Tally accounting, CRM with cross-promotions and an AI-powered customer experience.

## Live site
- Home: https://cronicweb.github.io
- Prototype: https://cronicweb.github.io/prototype.html

## Files
- `index.html` — landing page
- `prototype.html` — interactive app prototype showcase
- `app.css` — styling
- `app.js` — prototype interactivity

Commit changes to the `main` branch and they go live automatically within a minute or two.
